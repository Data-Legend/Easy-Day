# Easy-Day App 🚀

Your all-in-one productivity app for organizing tasks, books, and ideas in one place.

## Features

- **Daily Tasks** — Add, prioritize (Easy/Mid/High), and complete daily tasks with automatic daily reset
- **Books List** — Track your reading list with completion status
- **Archive** — Archived items from tasks and books, with clear-all option
- **Search & Filter** — Find tasks instantly by keyword or filter by priority
- **Inline Editing** — Double-click any task to edit its name
- **Statistics Dashboard** — Real-time completion rate and progress bar
- **Dark/Light Theme** — Toggle between dark and light modes (preference saved)
- **Keyboard Shortcuts** — Press `?` to see all shortcuts (N, S, T, 1–3, Esc)
- **Export/Import** — Download your data as JSON or restore from a backup
- **Toast Notifications** — Visual feedback for every action

## Tech Stack

- Vanilla HTML5, CSS3, JavaScript (ES6 Modules)
- MVC Architecture
- LocalStorage persistence
- CSS Custom Properties for theming
- Glassmorphism & micro-animations
- Fully responsive (mobile-first)

## Getting Started

1. Clone or download the project
2. Open `index.html` in any modern browser
3. Start adding tasks!

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `N` | Focus new task input |
| `S` | Focus search |
| `1` | Daily Tasks |
| `2` | Books List |
| `3` | Archive |
| `T` | Toggle theme |
| `?` | Show shortcuts |
| `Esc` | Close/clear |
